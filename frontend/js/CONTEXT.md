Classic scripts load in the order of `frontend/index.html`, share one global scope, and a file calls only upwards at load. Tests read the code through `app_js_text()` from `tests/_app_js.py`, never `frontend/js/app.js` directly.

Find a function: grep `docs/CODEMAP.md`, then read that line range.
