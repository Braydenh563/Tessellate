## Open, with a recommendation

- B4 connectors and shapes still repaint on every render. Recommendation: extend the key to shapes after auditing label placeholders and rough mode, and key a link by its endpoint geometry. Needs a cap on stale-path risk, so test with a moved endpoint.
- U18: undo on a board with 300 link sketches costs 412 ms render plus 187 ms in `wbThumbFlush`. Recommendation: schedule the thumbnail export on idle (it is not needed for the interaction), and let the connector key above remove most of the render.
- U20: the first code file open spreads its cost over `docAfterFirstPaint` (outline 51 ms, tools 15 ms) and the indent-mix scan (30 ms). Recommendation: one task each through the existing idle queue; only worth doing if a real device shows a long task, since each is under 100 ms at 1x.
- D18: the columns, mermaid and prose-suggest plugins each read the full text per keystroke (`docStr` hits, one real copy per version). Recommendation: gate each on `update.docChanged` plus a changed-range test against its own markers. Gain is small (copies are memoised); do it only with a measured keystroke over 50 ms.
- D22: opening a document pulls the whole `library` bundle, which includes whiteboard.js (718 KB), whiteboard-map.js (295 KB), d3 (273 KB) and graph.js. Recommendation: split `library` into a documents bundle and a whiteboard bundle in `TAB_MODULES`, with stand-ins for the calls documents make into the board code. A refactor with load-order risk, so a design step first; expected win is about 1.3 MB less on the first document open.
