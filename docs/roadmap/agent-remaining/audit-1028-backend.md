## Verified clean (traced, no finding)
- SSRF: web clip, web search and update downloads pin the resolved public address and re-check every redirect hop (core/webclip.py:83-148, core/security.py `public_addresses`; routes_update.py:218-250).
- SQL: every `f"SELECT..."` / DDL f-string interpolates constants or placeholder lists (search/engine.py:770, core/readings.py:43, database.py:2430, 2882-2914); no request value reaches SQL text.
- Deserialisation: no pickle, marshal, yaml.load, shell=True or os.system anywhere; embeddings stored as raw float32.
- Zip/tar: searxng tar uses `filter="data"`; backup restore uses `_safe_target`; folder import generates uuid names.
- Cookies: media cookie is HttpOnly, SameSite=strict, Secure on https and loopback; the API token is a header, so CSRF needs the header; Origin and Host checks cover rebinding.
- CSP: default `'self'`, no unsafe-inline or unsafe-eval, frame-ancestors none, user files served with a sandbox CSP and forced octet-stream unless image or PDF (routes_files.py:187-193).
- LAN: bind is loopback unless the switch is on and a password exists (core/netbind.py:173-181); first-run LAN is refused.
- Uploads: 50 MB per file, suffix allowlist, random names; `/media/{filename}` rechecks suffix.
- Open routes were walked: `/health`, `/instance`, `/auth/*`, `/logs/client`, Pyodide and translate files (name looked up in an allowlist), reminder notification token (HMAC, scoped, 24 h).
