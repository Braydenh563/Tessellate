# Deep audit 2026-11-08: perf (companion, diagram builder, document editor, Settings, composer latency)

Head 41b52ad9. Read-only audit; this is the only file written. Server on 8795
(8791 and 8793 were held by other sessions' servers, so not used), scratch data
dir `.../scratchpad/aud/data`, seeded 500 notes, 20 boards, 10 documents (the
asked-for 200/20/10 raised to 500 for the composer). Chromium via Playwright at
1440x900 dark, CDP 4x CPU throttle, service worker blocked. Probes are in the
session scratchpad `.../scratchpad/aud/p*.js` (PerformanceObserver `longtask` and
`long-animation-frame`, CDP `Performance.getMetrics` deltas, `Memory.getDOMCounters`,
devtools.timeline trace, CPU profile). **The host load average was 6 to 11 on 4
cores the whole time, so milliseconds are upper bounds; counts (layouts, style
recalcs, nodes, listeners, requests, long tasks) are trusted.** Every provider is a
fake transport (CLAUDE.md 4); the slow model is `fake_ollama_server.py` with
`FAKE_OLLAMA_DELAY=8`; no real inference.

Skipped as already held: 1031 PF1 to PF6 shapes are re-measured only where a number
moved or the cause is new; perf1667-1107 "left" items are marked "still open,
re-verified" where I reproduced them.

## Already good (measured)

- Companion catalogue is fetched once, only when the buddy schedules, and silent on failure (P11).
- Companion "You" is near free at rest: 0 layouts, 32 recalcs per 10 s; "Off" is 0.
- Document reopen and doc-to-doc switch do not leak nodes or listeners after GC (4 reopens: -5 nodes, 0 listeners; 8 switches: -94, 0).
- `#tag` completion: 1 cached `/tags` fetch, 69 to 76 ms per key.
- A slow model never blocks other routes (parallel `/entries` 9 to 27 ms during an 8 s model wait).
- Diagram block drag: 25 moves at about 45 to 80 ms each, 4 layouts and 118 style recalcs (4.7 per move) in total, no long task during the drag, 1 after the drop (55 ms).
- Settings search is not O(rows) per key any more after the first key (keys 3 onward 8 to 31 ms of script each in the profile).
- Complexity ratchet tests ran and reported no failure (158 seeded functions; the top seeds are `composer_voice._patterns`, `build_tree.grouping`, `_Markdown.block` at 28).
- No page errors and no console errors in any of the probes.
