## Left or known limits

- Cancel, rename, restore and add-to-today are read by the engine only where it answers (no model, or Ask "From your notes"). With a model up the model reads the words; a typed reader in the model path is not built.
- "rename the note X to Y" and the other note acts name the note by its words; a title with " to " in it splits at the first one.
- A rename onto an existing tag or category (a merge) is refused and left to the Tag manager and Manage categories, since Undo cannot split a merge.
- Restoring a private note from Chat is refused (the bin lists it, Chat does not touch it); a locked vault also refuses a tag a private note holds.
- The stale lock covers the add-to-today card only; other `edit_note` cards still write the whole text without a `base_hash`.
- Not driven in a browser: the cancel flow's card closing (`event.cancel` in `renderActCard`) is covered by the stream test and `node --check`, not by a Playwright run.
