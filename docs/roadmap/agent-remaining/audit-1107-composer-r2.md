## Class summary (what to fix by rule)

1. A note's text that is not prose (table row, one word, checkbox) must still be a quotable unit: E1, E11, E16, E19, E8 (one reader, `composer_read`).
2. Subtraction and comparison words (not, but not, nothing, cheaper, older, costs more) must not become subject terms: E2, E9, E10, E21.
3. A property ask on a note that lacks the property must say so, never leave the note or fall to another: E4, E12, E13, E20.
4. Follow-on subject must survive three turns and be the same in Ask and Chat: E5 (with research row 6, D6).
5. Never state an absence about a topic a note names: E1, E3, E11, E15, E21 ("only a title", "nothing about", "general knowledge" are claims).
6. Quotation marks and a note's own words are verbatim: D8, E18.
7. Money: a limit is not a budget, a symbol is not changed: E6.
