## Found, not fixed

- Where the steady-state restyles come from (trace attribution, Notes, Atlas settled, 1x): about half follow the
  pacer's reads, the rest follow rAF and timer beats (`lag-watch.js:280` wrapper, `atlas-life.js:321`
  `atlasTailFrame` every 400 ms, `atlasBreathFrame` writing `g.nmb-torso` `style.scale` every 100 to 200 ms). Each
  frame re-resolves every running animated node (about 65 in Atlas, 10 ms at 4x), so the cost is the number of
  frames, not the animations' own kind: the loops are compositor-only.
