# gods-1101: the god modules split by responsibility (ranked row 36, AR3)

## Design

**Rule for every cut.** A pure move: whole top-level blocks, text unchanged,
re-exported from the old module so `composer.X` and `routes_chat.X` still
work. A new module imports only modules below it, never its old hub, so no
cycle at load or lazily (`tests/test_complexity.py`; the lazy group is 0
today and stays 0). A name a test patches on the hub stays in the hub, with
everything that reads it, or the test patches the new home (one case:
`composer.rephrase`, read by `compare_sides`, now `composer_ask`).
`scratchpad` tooling: an AST pass lists each block's free names; a block
that reads a name left in the hub is not movable.

**composer.py (6,376 lines): the pipeline stays, the layers leave.** In
import order, each layer importing only those before it:

1. `composer_phrases`: `PHRASES`, the closed joining-word list, `phrase_options`.
2. `composer_ask`: reading the question (shape, `rephrase`, stems, synonyms,
   `subject_terms`, `compare_sides`, `asks_time`, the user's clock).
3. `composer_read`: a note read into sentences and list items (`Sentence`,
   `NoteView`, `read_note`, pictures, titles).
4. `composer_select`: scoring and choosing (`select`, `_Meaning`,
   `centrality`, `disagree`, the tuning constants).
5. `composer_answer`: `_Answer`, the answer being built, and its session salt.
6. `composer_quote`: a quote said (picked wording, lowered capital, a list as
   one sentence, a checklist counted).
7. `composer_unfound`: the question's words no note has.
8. `composer_body`: the layout by shape (opening, lead, others, timeline,
   comparison, broad, still open, newest).
9. `composer_dialogue`: next questions, follow-ons, `Dialogue`.
10. `composer_smalltalk`: `SOCIAL` and the social replies.
11. `composer_intent`: `Plan` and `plan` (not `composer_plan`, the deadlines).
12. `composer_help`: help with the app's own tools, utilities.
13. `composer_empty`: an empty window, a constraint that kept nothing,
    "nothing found".
14. `composer_recall`: a recall by time and a topic's overview.

`composer.py` keeps `compose`, `_compose`, `brief`, `split_parts`, the
clarify and readings step and the act registration: about 1,000 lines.
