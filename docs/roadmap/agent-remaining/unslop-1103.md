## Verdict

Not vibe-coded at the system level, and the tokens are really obeyed: on the main surfaces every font size is on the ramp, every border is 1px, every spacing value is a token except a short tail (finding 21), contrast has no real failure (see "Measured clean"), the error and empty states are one component with real copy. What still reads as assembled is local, and it is the same three kinds of thing each time: (a) a phone layout that was never folded (findings 1, 2, 4, 23), (b) one control that brings its own style into a recipe row (5, 6, 7, 12, 24), (c) a vertical rhythm set by a mechanism instead of a token (3, 13). Fix the first five and the app reads as designed on a phone and on the Dashboard, which is where a stranger looks first.

## What I could not verify

- Keyboard reach, focus order and focus-ring visibility: not swept (the brief was unslop, not accessibility); `scratchpad/ui-sweeps/touch.js` and `docks.js` cover those and were not run.
- Real inference, a model-connected chat, and any state that needs one (Ask results, agent plans). Chat was measured with "No model connected".
- 390 touch sweeps ran in Chromium's mobile emulation, not a phone: the sticky `:hover` on the Sintra day trip chip (a stray "⋮" inside it in the Notes screenshots) is `:hover` left by the emulated pointer and is not counted.
- The three "Probe" documents and two of the seeded notes' dates read oddly ("9h ago", a document titled "Probe"): `seed-showcase.py` or a prior sweep left them; not counted as app findings.
- Finding 8's cause (the 4px) is read from computed `padding` and `margin` of `.library-view-section`, not traced through the cascade. Finding 3's cause (row-span rounding) is inferred from the gap values, not read from the code.
- The board and mind map were measured on the toolbar and chrome only; object content (the saturated per-branch colours) is user data and not judged. The mind map at 390 shows the topics cropped by the viewport, which is a pan, not a layout fault.
- Density settings (compact, spacious), other looks (`LOOK=`), and `GLASS=off` were not run; every number above is the default look and Comfortable density.
